# STAR Development Centre

This repository currently contains an initial Next.js **preview**, not the complete website. The original project archive has additional pages, imagery, a prospectus and Supabase-backed request forms that have not yet been migrated.

## Preview on Vercel

Import this GitHub repository into Vercel with the Next.js preset. This preview needs no environment variables. It has a responsive homepage, programme overview and contact links.

## Not live yet

Online registration and bookings are **not operational**. Do not accept sensitive player information until secure database setup, safeguarding/privacy review, availability approval, and end-to-end testing are complete.
